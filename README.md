# testrepository001

Repository di test personale per mini-progetti, esperimenti e prototipi vari.

## Struttura

```
projects/
  web/       → mini app HTML/CSS/JS
  scripts/   → script Python, Bash, etc.
  apis/      → test di API e client REST
  data/      → esperimenti con dati, JSON, CSV
  misc/      → tutto il resto

templates/
  html-basic/      → punto di partenza per app web
  python-script/   → punto di partenza per script Python
```

## Come aggiungere un progetto

1. Scegli la categoria giusta in `projects/`
2. Crea una cartella con nome descrittivo (es. `projects/web/todo-app/`)
3. Lavora dentro quella cartella
